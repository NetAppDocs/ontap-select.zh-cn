= ONTAP Select支持ONTAP功能
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select支持大多数ONTAP功能。部署集群时，许多ONTAP功能都会自动为每个节点授予许可。但是，某些功能需要单独的许可证。


NOTE: ONTAP Select 通常不支持具有特定于硬件的依赖关系的ONTAP 功能。



[[ontap-features-licensed-by-default]]
[[licensed-ontap-features]]
== 默认情况下获得许可的 ONTAP 功能

默认情况下，ONTAP Select 支持以下 ONTAP 功能并已获得许可。

[cols="1,1,1"]
|===
| 功能 | 了解 | 说明 


| 自主勒索软件防护（ARP） | link:https://docs.netapp.com/us-en/ontap/anti-ransomware/index.html["ONTAP 自主勒索软件防护"^] | ONTAP Select 仅支持 ARP 手动更新。 


| CIFS | link:https://docs.netapp.com/us-en/ontap/smb-admin/index.html["ONTAP SMB"^] |  


| 重复数据删除和数据压缩 | link:https://docs.netapp.com/us-en/ontap-restapi/storage_volumes_endpoint_overview.html["管理存储卷"^] |  


| 使用密钥管理互操作性协议 (KMIP) 进行外部密钥管理 | link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/configure-netapp-volume-encryption-concept.html["启用和配置外部密钥管理"^] |  


| FlexCache | link:https://docs.netapp.com/us-en/ontap/flexcache-writeback/flexcache-write-back-guidelines.html["ONTAP FlexCache 回写"^] | ONTAP Select 支持带回写的 FlexCache 缓存卷。*注意*：使用 ONTAP Select 进行 FlexCache 回写存在限制。有关详细信息，请参阅 link:concept_ots_overview.html#flexcache-write-back-with-ontap-select["使用 ONTAP Select 的 FlexCache 回写"]。 


| FlexClone | link:https://docs.netapp.com/us-en/ontap/volumes/flexclone-efficient-copies-concept.html["ONTAP FlexClone 卷"^] |  


| iSCSI  a|

* link:https://docs.netapp.com/us-en/ontap-restapi/protocols_san_iscsi_services_endpoint_overview.html["管理 iSCSI 服务"^]

| NFS | link:https://docs.netapp.com/us-en/ontap/nfs-admin/index.html["NFS 协议的 ONTAP 文件访问"^] |

| 基于TCP的NVMe | link:https://docs.netapp.com/us-en/ontap-restapi/protocols_nvme_services_endpoint_overview.html["管理 NVMe 服务"^] |

== 单独许可的ONTAP 功能

您需要为以下 ONTAP Select 支持但默认情况下未获得许可的 ONTAP 功能获取单独的许可证。

[cols="1,1,1"]
|===
| 功能 | 了解 | 注 


| FabricPool | link:https://docs.netapp.com/us-en/ontap/concepts/fabricpool-concept.html["ONTAP FabricPool"^] | 使用StorageGRID时、不需要FabricPool许可证。 


| MetroCluster SDS | link:reference_plan_ots_mcc_sds.html["适用于 ONTAP Select 的 MetroCluster SDS"] | 这是 ONTAP Select 高级许可证产品。 


| SnapMirror 云 | link:https://docs.netapp.com/us-en/ontap/concepts/snapmirror-cloud-backups-object-store-concept.html["SnapMirror 云备份到对象存储"^] | 您需要 link:https://mysupport.netapp.com/site/help["创建非技术支持案例"^] 获取 SnapMirror 云许可证。 
|===
