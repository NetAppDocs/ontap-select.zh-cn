= 确保ONTAP Select部署的安全
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以通过使用命令行界面根据需要更改 Deploy 虚拟机管理员帐户的密码来保护 ONTAP Select 部署。

.步骤
. 使用管理员帐户登录到 Deploy 实用程序命令行界面。
. 更改密码： `password modify`
. 根据您的环境情况对所有提示进行响应。
