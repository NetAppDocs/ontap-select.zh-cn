= 确定 ONTAP Select 的容量池许可证大小
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
根据可用空间和集群配置开销计算 ONTAP Select Capacity Pool 许可证大小，以确保为部署提供足够的许可容量。

在确定容量池许可证大小之前，应查看以下注意事项：

* 在硬件 RAID（VMDK）和软件 RAID（NVMe 或 SSD）配置中，许可证消耗是根据分配给数据聚合的数据磁盘或数据分区计算的。
* ONTAP Select 将 RAID-DP 奇偶校验磁盘和分区排除在许可证消耗之外。您仅获得添加到聚合的数据分区和磁盘的许可，因此 RAID-DP 奇偶校验开销不会消耗额外的许可证容量。
* 备用驱动器容量不包括在聚合可用容量中，也不会消耗许可证容量。
* 奇偶校验磁盘专用于数据保护。它们不为卷和数据提供可用存储，也不计入可用容量。


容量池许可证的许可容量为全 TB 量，至少为 2 TB。您可以通过将可用空间量乘以开销系数来计算许可容量。开销系数估计将从可用空间中获取的 ONTAP Select 软件开销容量，并适用于确定 NVMe、SSD、HDD 或虚拟驱动器的 ONTAP Select 容量。单节点和多节点（基于 HA 对）集群之间的开销系数不同：

* 单节点集群的开销系数为 1.13
* 多节点集群的开销系数为 2.67


您需要根据可用空间来计算许可容量，以确保您有足够的容量进行部署。例如，您需要一个 HA 对 20 TB 的可用容量（每个节点 10 TB）：

* 对于 HA 对，数据在两个节点之间复制以实现冗余，因此对于 HA 对中的 20 TB 可用数据，如果其中一个节点脱机，则每个节点需要有 20 TB。
* 2.67 的系数使每个节点的容量翻倍，并增加了 ONTAP Select 运行所需的开销容量（0.67）。
* 每个节点的许可证容量为 27 TB（10 x 2.67 = 26.7）。对于 HA 对，您需要两个 27 TB 的许可证才能拥有 20 TB 的可用容量。
